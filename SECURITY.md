# Security Policy

## Supported versions

Security fixes land on the latest minor release only. Upgrade to the current minor to receive them.

## Reporting a vulnerability

Report vulnerabilities privately through GitHub security advisories, not public issues or pull requests.

1. Open the repository's **Security** tab.
2. Choose **Report a vulnerability** (or go to https://github.com/KalebCooper/swift-indefinite-loader/security/advisories/new).
3. Describe the issue, the affected version, and a minimal reproduction if you have one.

Expect a best-effort acknowledgement within a few days. Fixes follow coordinated disclosure: please keep
the report private until a patched release is available. Valid reports are credited in the release notes
unless you ask otherwise.
